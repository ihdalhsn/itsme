Project 03 · Personal Finance & Zakat

Product concept · Planned mobile app Haul

Haul

Gold savings and zakat due-date tracker

Making the nearest gold-zakat obligation easy to trace.

Problem

The main difficulty is not simply calculating zakat, but tracing which gold holding is approaching its haul and which obligation should be prioritized.

Product direction

A mobile dashboard that records each gold purchase and surfaces the nearest haul, supported by price updates and practical notifications.

Planned data & features

  • Gregorian Purchase Date
  • Hijri Month / Haul Reference
  • Manufacturer & Weight
  • Quantity & Serial Number
  • CertiEye Evidence
  • Purchase Price
  • Daily Gold Price API
  • Nearest-Haul Dashboard
  • Priority & Notifications
  • Zakat Calculation Support

Product thinking

The scope is deliberately centered on the user's real pain point: tracing time and priority. Secondary features are added only when they support that decision.

Build the reminder and prioritization workflow first — not a large financial platform that distracts from the core problem.
